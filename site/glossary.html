Glossary

Block-level elements
Elements of a webpage that form a visible block. These elements always begin on a new line, and whatever procedes these elements is always on a new line. They can normally include nested elements
Inline elements
Elements of a webpage that appear inline with text, and wrap around at line endings. These elements cannot usually contain block-level elements.
Structural elements
Elements that visually sperate and distinguish certain other elements from each other, dictating the structure of the webpage.
Semantic elements
Elements that allow the "understanding" of the webpage's content.
Hyperlink
A link within a hypertext file or document that leads to another location or file.
